## 目标架构（驱动/报告）

### Selenide 驱动托管（新 `driver` 包，替换 `factory` 包）
- `driver/SelenideManager`（ThreadLocal）：
  - `createDriver(String browserName, Method method)` → 构建 `SelenideConfig` → `new SelenideDriver(config)` → 存入 ThreadLocal
  - `getSelenideDriver()` / `getWebDriver()` / `hasDriver()` / `closeDriver()`（`SelenideDriver.close()` + `ThreadLocal.remove()`）
  - 每个线程独立实例，天然并行安全；不共享静态 `Configuration`
- `driver/SelenideConfigFactory`：
  - 浏览器映射：`CHROME→chrome`、`FIREFOX→firefox`、`EDGE→edge`、`INTERNETEXPLORER→ie`
  - `.headless(method.isAnnotationPresent(Headless.class))`（IE 忽略）
  - `.remote(...)` 取 `SEConfigs.seleniumHubUrl()`（非空时）
  - `.browserCapabilities(...)`：复用 `CapsUtils` 的 caps.json + cli args + extensions 构建 `ChromeOptions/FirefoxOptions`；`@Incognito` → Chrome `--incognito` / Firefox `-private` / Edge `--inprivate`
  - `.screenshots(false)` / `.savePageSource(false)`（截图仍由 AShot + Allure 统一处理）
- `WDManager` 保留为**兼容 facade**：`getDriver()` → `SelenideManager.getWebDriver()`；`quitAndClearDriver()` → `SelenideManager.closeDriver()`；删除 `setDriver/quitDriver/removeDriver`（3.0.0 breaking）
- `SeleniumParallelTestListener.beforeInvocation`：`SelenideManager.createDriver(...)`；`@URL` → `getSelenideDriver().open(url)`
- `SeleniumParallelTestListener.onStart`：删除 WDM 批量下载整段逻辑
- `TestResultListener`：截图前检查 `hasWebDriverStarted()`，结束时 `SelenideManager.closeDriver()`
- `SeleniumParallel`（遗留类）：`driverManager` 字段改为 SelenideManager；`openUrl` 用 `SelenideDriver.open()`

### Allure 报告（替换 Extent 三层节点）
- TestNG XML 天然层级 `Suite → Test("Selenium Test - CHROME") → Class → Method`，Allure 自动映射
- 新建 `report/AllureReport.java`：`describeTest`（`Allure.description`、`Allure.label("owner"/"tag"/"browser")`）、`step`、`attachScreenshot`（`Allure.attachment` + `AttachmentOptions.withFileExtension("png")`）
- `TestResultListener` 失败时附加截图；PASS/FAIL/SKIP 状态由 Allure TestNG listener 自动记录
- `ScreenshotManager.capture()` 返回绝对路径（Allure 需要真实文件）
- `src/main/resources/allure.properties`: `allure.results.directory=build/allure-results`
- 不用 AspectJ（全部编程式 API）

### ReportPortal（opt-in，仅文档）
- 消费方加 `com.epam.reportportal:agent-java-testng:5.6.8`（test scope）+ `reportportal.properties`
- Listener ServiceLoader 自动生效；自定义 `testng.listeners` 时需追加 `com.epam.reportportal.testng.ReportPortalTestNGListener`
- 截图示例：消费方 listener 调 `ReportPortal.emitLog(msg, LogLevel.INFO.name(), new Date(), file)`
- 警告：RP 需可访问 server，未配置时不要加入 classpath
